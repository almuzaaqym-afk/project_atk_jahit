PROJECT ATK JAHIT
PHP Native + XAMPP + MySQL/MariaDB

CARA MENJALANKAN
1. Extract folder project_atk_jahit ke C:\xampp\htdocs\
2. Start Apache dan MySQL di XAMPP.
3. Buat database bernama project_atk_jahit.
4. Import database/project_atk_jahit.sql melalui phpMyAdmin.
5. Buka http://localhost/project_atk_jahit/pelanggan/

CATATAN
- Halaman sebelum login: pelanggan/index.php
- Halaman sesudah login: pelanggan/user/index.php
- Navbar/footer guest dan user dipisahkan.
- Logo: pelanggan/assets/images/logo.png
- Fitur project saat ini difokuskan sampai detail produk.
